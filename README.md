📊 Project Overview
This project focuses on analyzing automotive sales and inventory data using Microsoft Power BI.
The dashboard provides an interactive overview of business performance, helping explore sales transactions, vehicle availability, 
warehouse operations, dealer performance, and sales representative activities.
The objective is to transform raw automotive data into meaningful insights through data visualization and business intelligence techniques.

🎯 Project Objectives
Monitor overall automotive sales performance.
Analyze sales transactions and invoice values.
Track vehicle inventory and available units.
Evaluate warehouse performance.
Compare dealer performance.
Analyze sales representative performance.
Monitor deal statuses and sales trends over time.

🛠️ Tools & Technologies
Microsoft Power BI
Power Query
DAX
Data Cleaning & Transformation
Data Modeling
Data Visualization
Interactive Dashboards

📈 Key Performance Indicators (KPIs)
Total Invoice Value
Total Quantity
Total Transactions
Available Units
Average Stock Age

🔍 Dashboard Analysis
1. Overview Analysis
Provides a general summary of automotive sales and inventory performance through key business indicators.

2. Deal Status Analysis
Explores transaction and deal statuses to understand sales progress and distribution.

3. Warehouse Analysis
Evaluates warehouse performance and provides insights into inventory distribution and stock availability.

4. Vehicle Analysis
Analyzes vehicle-related data to understand sales performance and inventory levels across different vehicles.

5. Sales Representative Analysis
Compares sales representative performance and their contribution to overall sales.

6. Dealer Analysis
Evaluates dealer performance and analyzes sales distribution across dealers.

7. Date Analysis
Explores time-based sales and inventory trends to identify performance patterns over time.

📌 Dashboard Features
Interactive dashboard pages.
KPI cards for business performance monitoring.
Dynamic filters and slicers.
Multiple analytical perspectives.
Visual analysis of sales and inventory data.

💡 Business Value
This dashboard provides a comprehensive view of automotive business operations.
It helps users monitor sales performance, evaluate dealer and sales representative contributions, understand inventory distribution,
and identify trends that can support better operational and business decisions.
